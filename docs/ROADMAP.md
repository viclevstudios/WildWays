# Roadmap

This roadmap describes the intended direction for WildWays. Items may move as the design becomes clearer.

## Phase 1: Foundation

- Keep the Fabric 26.2 project building cleanly on Java 25.
- Replace template metadata, example code, and placeholder mixins with real mod structure.
- Establish common registries, identifiers, and configuration patterns.
- Document testing and release expectations.

## Phase 2: Progression Gates

- Add additional prerequisites before reaching the End.
- Connect key progression steps to more varied vanilla activities.
- Make structure exploration relevant to progression.
- Keep all requirements discoverable in normal gameplay.

## Phase 3: Grind Reduction

- Reduce the incentive to repeatedly reset villager trades.
- Add a healthier alternative path for obtaining important trades or resources.
- Review XP progression and common farm pressure points.
- Keep useful player automation possible without making one farm the obvious answer.

## Phase 4: Exploration And Travel

- Improve structure loot where it supports exploration.
- Add better paths to finding selected structures or biomes.
- Create stronger early-game alternatives to late-game mobility and utility items.
- Give minecarts and other underused travel systems more practical value.

## Phase 5: Long-Term World Pressure

- Explore mob scaling or world-state pressure that keeps late-game survival relevant.
- Add late-game reasons to revisit older systems, locations, and resources.
- Balance multiplayer pacing through playtesting.

## Release Criteria

- The mod builds with `.\gradlew.bat build`.
- New gameplay changes are tested in a client world.
- Server/client boundaries are checked for dedicated-server compatibility.
- Player-facing behavior is reflected in documentation when needed.
