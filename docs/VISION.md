# Vision

WildWays is a vanilla-style Minecraft progression mod for players who want worlds to last longer and feel worth exploring.

The project is built around a simple idea: progression should invite players into more of Minecraft instead of pushing them toward the fastest gear route, the strongest farms, and the same repeated optimizations every server.

## Goals

- Make progression less rushable without making it feel artificially blocked.
- Reduce boring grind where the best strategy is repetitive reset behavior.
- Make exploration, travel, building, and survival more useful throughout a world.
- Give underused vanilla systems, mobs, structures, and items more reasons to matter.
- Keep the mod quiet and believable inside vanilla Minecraft.

## Design Principles

- Prefer incentives over hard punishment.
- Prefer multiple viable paths over one forced route.
- Preserve multiplayer pacing so groups do not finish the world in a single sprint.
- Keep early and mid game choices meaningful.
- Avoid changes that feel like chores added only to slow players down.

## Non-Goals

- WildWays is not intended to become a total conversion.
- WildWays should not replace Minecraft's core identity with a quest-pack structure.
- WildWays should not make late-game progress impossible for casual players.
- WildWays should not depend on a large external mod ecosystem to be useful.
