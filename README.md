# WildWays

Hey there! This Minecraft Mod is a small side project of mine where I try to improve Minecrafts Progression System.

![Static Badge](https://img.shields.io/badge/Work%20in%20Progress%20-%20%23ff9913)


## The Problem
My last few Minecraft Survival Servers all went like the following: 

_We started the world, everyone rushed to get the best gear and farms as fast as possible, and after a few weeks the servers died out again._

Most players spent more time doing boring grinding, like resetting villagers for good trades or copying the same XP farm tutorial for the 5th time, then doing the things that really is fun for them, like exploring, building or creating cool stuff with redstone.

At the same time, some really interesting features of the game are almost never used because there are better ways to do these things later in the game. Just think of Minecarts.

This is a direct problem caused by Minecraft's Progression System. Sprinting through the game to get the best gear possible is encouraged, even though a lot of the ways to get there are boring, like resetting villager work stations. Meanwhile, fun things, for example structures like the Ancient City, aren't part of the progression at all.

To fix this, this mod aims to make the Progression less rush able while also making certain parts of it less grindy and some fun parts of the game more useful. 

## Planned Features
- a bigger number of prerequisites to get into the end, so that more aspects of the game are needed to open the end portal
- good early game alternatives to late game items to discourage the rush for the best gear
- a nerf to villagers while also implementing a alternative for resetting their trades
- more loot in structures around the world and better ways to find certain structures / biomes to encourage exploration (Mojang coincidentally already implemented a part of that in the latest Snapshot)
- mobs getting stronger while you progress so that your world isn't completely free of threats in the late game
- more use cases for lesser used items / mobs like Sniffer, Fletching Tables, Endermites or certain food items
